# Omada Network Manager for Homey — Support

Public support and issue tracker for **Omada Network Manager for Homey**.

This repository contains **support information only**. The application source code is maintained separately.

## Support / Ondersteuning

Use the **Issues** tab to report a bug or request a feature.

- Bug report: describe what happened, what you expected, your Homey firmware version, app version, and Omada controller/model where relevant.
- Feature request: describe the use case and what you would like the app to do.

## Privacy

Please **never post**:

- Omada Client Secret
- access tokens
- passwords
- Authorization headers
- cookies
- controller backups
- raw API responses containing private network data

When diagnostics are requested, use the anonymized diagnostics export generated by the Homey app and check it before uploading.

## Nederlands

Gebruik het tabblad **Issues** om een fout te melden of een functie voor te stellen.

Vermeld bij een foutmelding bij voorkeur je Homey-firmwareversie, appversie en relevante Omada-controller/apparaten. Deel nooit wachtwoorden, Client Secrets, tokens of andere geheime gegevens.
